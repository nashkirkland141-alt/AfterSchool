AFTERSCHOOL

1. Extract the AfterSchool folder.
2. Open index.html in a modern browser, or upload the entire folder to a static web host.
3. Keep games.json, the four wallpaper JPGs, and the games folder beside index.html.

Included games: 2056 HTML game files.
The catalog is searchable. Open Games to browse and launch games. Use Settings to change the background. Music accepts local audio files.

Note: Some included games may rely on remote assets or browser features and may not work in every browser or when opened from file://. Hosting the folder on a static web host is recommended. Only use games and assets you have permission to distribute.
